# Структура EPF 1С 8.3 — Экспорт кодов Честного ЗНАК

## Форма

Создать внешнюю обработку с управляемой формой.

Реквизиты объекта формы:
- КоличествоКодов — Число, длина 10, точность 0, значение по умолчанию 180.
- Каталог — Строка, длина 500.
- Статус — Строка, длина 1000.

Команды формы:
- ВыбратьКаталог
- СохранитьCSV

Элементы:
1. Группа «Параметры»
2. Поле «Количество кодов»
3. Поле «Папка сохранения»
4. Кнопка «Выбрать папку»
5. Большая кнопка «Сохранить CSV»
6. Поле «Статус»

## Поведение

Кнопка «Выбрать папку» открывает выбор каталога.
Кнопка «Сохранить CSV»:
- проверяет каталог;
- если КоличествоКодов = 0, выгружает все;
- иначе выгружает указанное количество;
- создаёт codesOrder_YYYY-MM-DD_HH-mm-ss.csv;
- формат строки: "ПолныйКМ";"GTIN";"Наименование";
- полный КМ сохраняется целиком;
- ASCII 29 (GS) заменяется одним пробелом;
- CSV UTF-8 без BOM;
- исходные данные в 1С не изменяются.

## Важное ограничение

EPF — бинарный формат 1С. GitHub может хранить исходный BSL/EDT/XML-проект, но корректный бинарный .epf должен быть создан средствами 1С 8.3. Поэтому этот файл является спецификацией готовой формы EPF, а не притворным бинарным EPF.
